# Lumen TV 3.0.0

First release under the Lumen TV name.

## What changed

- **Rebranded** from Tigris to Lumen TV: new application id `com.luumlabs.lumen`, new label,
  new README and NOTICE. The original MIT copyright notice is preserved in `LICENSE`.
- **Fully English** interface (296 strings plus the resource entries).
- **Updater** points at this repository's releases and verifies the fork signing certificate.
- **Install confirmation** is now launched from the background updater, so the system dialog
  actually appears instead of being silently dropped.

## Install

This is a new application id, so it installs alongside Tigris rather than replacing it.
Remove the old package if you don't need it any more:

```bash
adb uninstall com.leslie.tvhome
adb install -r Lumen-v3.0.0.apk
adb shell cmd package set-home-activity com.luumlabs.lumen/.HomeActivity
```
