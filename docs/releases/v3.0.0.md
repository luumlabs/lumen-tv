The first release under the Lumen TV name: Tigris, translated into English, rebranded and set up
to update from this repository.

## Highlights

- **A fully English interface**, from the home screen and Control Center to every settings page.
- **A new identity.** Lumen TV uses its own application id, `com.luumlabs.lumen`, so it installs
  alongside Tigris instead of replacing it.
- **Updates from this repository.** The built-in updater checks Lumen TV's releases and verifies
  every package against the Lumen TV signing certificate before installing it.

## Fixes

- The system's install confirmation now appears when an update is installed from the background.
  It could previously be dropped without showing.

## Moving from Tigris

Lumen TV is a separate app, so your Tigris settings are not carried over. Once Lumen TV is
installed and set as the home screen, you can remove Tigris:

```sh
adb install -r Lumen-v3.0.0.apk
adb shell cmd package set-home-activity com.luumlabs.lumen/.HomeActivity
adb uninstall com.leslie.tvhome   # optional: remove Tigris
```
