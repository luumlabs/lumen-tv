# Tigris 2.0.3 — Preview / 电视测试版

**预发布版本（Pre-release）：请先在电视上验证，确认后再升为正式版。**

基于 2.0.2，修复：
- 控制中心的胶囊 / 圆形按钮出现菱形、透镜形：修正 CPU Liquid Glass 超大圆角半径计算。
- 设置/输入源等弹层按钮聚焦放大时被截边：取消 Sheet 内外两层的子视图裁剪。
- 壁纸选择页面卡片聚焦放大时边缘显示不全：放开根容器 padding 裁剪。
- README 新增真实 Issue/PR 机型兼容记录、英文版和官网 Tigris 图标（应用运行逻辑无变化）。

**测试重点 / Test checklist**
1. 控制中心待机 / Wi-Fi / 输入源按钮的玻璃轮廓是否呈正常圆角，且焦点完整。
2. 输入源或其他选项弹层中，聚焦按钮的两侧和四角是否被裁掉。
3. 壁纸选择页面四边的卡片获焦放大后是否完整显示，移焦能否恢复。
4. Android TV 返回键、输入源、亮度和音量的原有行为是否保持正常。

**安装包 / Assets**
- `Tigris.apk` — 标准版；一般 Sony、Google TV 和其他正常允许第三方 HOME 的电视使用。
- `Tigris-guard.apk` — Guard 版；TCL / 雷鸟国行固件通过 T-Cast 多屏互动安装。
- `SHA256SUMS.txt` — 文件校验信息。

**重要：签名与升级 / Signature & upgrades**
本项目目前使用 Gradle 的 **debug 签名配置**。不同构建机器的 debug 证书可能不同：如果在 v2.0.2 上执行 `adb install -r` 失败并提示 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`，这是签名不匹配，不是功能回退。卸载重装会清空应用配置，**请先备份设置/照片并确认再卸载**，不要自动删除现有应用。Android 9（API 28）以下无法安装官方 APK。当前 Release 是预发布，**不会自动替换 v2.0.2 的正式稳定版**。

**English:** Preview for TV hardware testing. Fixes the CPU glass rounded-pill geometry and focus clipping in popups and wallpaper selection. Standard and Guard APKs are included. Debug-signed APKs from different machines may not support in-place upgrades; back up settings before uninstalling. Please report exact model, Android version, and test observations.
