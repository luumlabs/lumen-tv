# Lumen TV 3.3.0

## Changes

- **Parallax inside the tile.** When focus arrives, the artwork starts displaced against the
  direction of travel and settles back to centre while the card tilts, so the tile reads as
  layers with depth. A 6% overscan on the artwork keeps the drift from exposing an edge.
- **A touch more lift**: focus scale 1.12 → 1.14.

The focus tween already used an overshoot spring (`OvershootInterpolator(1.6f)`) with a 260 ms
in / 170 ms out, plus the edge "bump" when the D-pad hits a wall, so this release refines the
motion rather than replacing it.
