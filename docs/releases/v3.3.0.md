More depth in the focus animation.

## Improvements

- **Parallax inside the tile.** When a tile is selected, its artwork starts slightly offset against
  the direction you moved and settles back into place while the tile tilts, so it reads as layers
  with depth rather than a flat card.
- **A little more lift** on the selected tile.
