# Lumen TV 3.0.1

## Changes

- **The Input button is hidden when the TV exposes no HDMI inputs.** Some firmwares
  (Hisense/VIDAA) register nothing with the Android TV input framework and keep their own
  picker behind a signature permission, so the button could only ever say
  "Can't read the TV's inputs". It now disappears on those TVs and keeps working on
  Sony, TCL, Xiaomi and anything else that reports inputs normally.
