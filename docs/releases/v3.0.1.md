A small fix for TVs that do not report their HDMI inputs to Android.

## Fixes

- **The Input control no longer appears where it cannot work.** Some firmwares, Hisense VIDAA
  among them, keep their input list private, so Control Center could only report that it couldn't
  read the inputs. On those TVs the control now stays out of the way. Sony, TCL, Xiaomi and other
  TVs that report their inputs are unaffected.

---

**Download:** `Lumen-v3.0.1.apk` (standard build). Newer releases also ship a guard build for TCL and FFalcon China firmware.
See the [installation guide](https://github.com/luumlabs/lumen-tv#installation).
