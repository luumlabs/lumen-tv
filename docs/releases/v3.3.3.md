# Lumen TV 3.3.3

## Fix

- **The dock glass no longer stays at the top with its tiles at the bottom.** The dock and the
  top-right status row were positioned from a cached scroll counter (`scrollY`) that only the
  RecyclerView scroll callback updated. A layout that moves the grid without a scroll event —
  moving a tile in *Edit Home Screen*, a reload after an install/uninstall, or a smooth scroll
  interrupted by re-layout — could leave the counter and the grid disagreeing: the glass stayed
  translated up while the rows were back at rest, which read as a blank glass panel at the top
  and shifted tiles below it.

  Now a single `syncDock()` derives the offset from the laid-out rows (`gridOffset()`), and the
  dock is re-derived after every grid layout, after `Edit Home Screen` ends, after a reload, when
  the home screen resumes, and on any key press. `requestChildRectangleOnScreen()` also asks the
  rows where the grid actually is instead of trusting the counter, so it no longer scrolls twice.

## Note

No visual change in normal use: the dock sits behind the first row at the bottom of the screen,
and slides up with that row when the app grid is expanded.
