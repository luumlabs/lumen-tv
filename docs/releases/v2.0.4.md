# Tigris 2.0.4

## 新功能

- 应用文件夹：长按应用创建文件夹，支持移动、改名、移出和解散。
- 上传头像：设置 → 上传头像，手机扫码上传或恢复默认。
- 软件更新与投屏：同一个液态玻璃页面检查 Tigris 和 MiracastReceiver 的 GitHub 正式版，支持安装投屏组件和可选自动更新。系统可能仍要求确认安装。
- 内置默认开机视频与设置背景；背景主体向左偏移，与按钮保持距离。自定义素材优先，已有开关配置保留。

## 体验改进

- 下滑渐入磨砂背景，Dock 保留底板并随第一排自然滑出屏幕；右上角时间和控件同步离屏，不占用遥控器焦点。
- 修正 Dock 背景采样错位、控制中心右键无法选择头像、过渡帧黑底混入玻璃背景的问题。
- 官网增加动态展示、真实航拍录屏、完整 Agent 安装指令、一行安装与还原入口。

## 安装与升级

标准版下载 `Tigris.apk`；TCL / 雷鸟使用 `Tigris-guard.apk` 并按安装说明设置桌面守护。

[官网安装说明](https://tigris-tv.pages.dev/#install) · [Agent 指引](https://tigris-tv.pages.dev/agent.md)

```sh
curl -fsSL https://tigris-tv.pages.dev/install.sh | KEEP_ADB=1 TV=192.168.1.20 bash
```

替换为电视 IP。覆盖安装保留配置，签名不一致时停止，不自动卸载。2.0.3 预发布使用了不同构建签名，不能保证直接覆盖；请使用与原安装一致的密钥构建，切勿为了升级直接卸载丢失设置。

2.0.4 起发布流程固定签名，SHA-256：`7d2b6be8a86ce8981e368dde4920869b90c8206137934a6d1fc89a2d1d1b6114`。

## 验证范围

Sony BRAVIA Android 12 已测试文件夹、头像、焦点、滚动与更新检查。Standard / Guard 构建、单元测试与 Android lint 通过。安装脚本通过模拟安装/还原测试，未做 macOS/Linux 真机安装验证。内置素材与布局本次仅打包和构建检查，未重新调整用户电视配置。不同电视的自动安装确认行为仍由系统决定。
