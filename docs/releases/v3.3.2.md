# Lumen TV 3.3.2

## Changes

- **The standard build declares the HOME intent with `android:priority="3"`.** Firmwares that
  resolve the home activity by intent priority now pick Lumen over a stock launcher that ships
  with priority 2, so Lumen can be the real default home instead of being kept in front by the
  accessibility guard.

  TCL clamps the priority of third-party HOME filters to 0 and ignores
  `cmd package set-home-activity`, so on TCL the stock launcher still wins the resolution while
  it is enabled. There the default-home setup is: install the standard build, make sure Lumen is
  the only enabled HOME activity, and disable the stock launcher for the user
  (`pm disable-user --user 0 com.google.android.apps.tv.launcherx`). The guard build remains the
  fallback for TVs where that is not acceptable.

## Note

The guard flavor is unchanged: it still declares no HOME activity at all.
