Lumen can now be the real default home screen on more TVs.

## Improvements

- **Preferred over stock launchers that rank by priority.** The standard build now declares a higher
  home-screen priority than most built-in launchers, so firmwares that pick the home screen this way
  choose Lumen, and the home guard is no longer needed on them.

## Note for TCL TVs

TCL firmware lowers the priority of third-party home screens and ignores the usual command for
choosing one, so its own launcher still wins while it is enabled. To make Lumen the default there,
install the standard build and disable the stock launcher for your user:

```sh
adb shell pm disable-user --user 0 com.google.android.apps.tv.launcherx
```

If you prefer not to, the guard build keeps working as before.
