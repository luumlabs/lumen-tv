# Tigris 2.0.5

## Desktop stability

- Automatic home takeover now requires a fresh, confirmed stock HOME window. Boot, wake and service recovery alone no longer bring Tigris in front of an app or HDMI input.
- A short settling delay cancels takeover when another window appears. Repeated vendor takeovers are rate-limited: after three automatic attempts in 30 seconds, the next attempt pauses automatic takeover for 60 seconds. The physical Home key remains available where the firmware delivers it.
- Delayed accessibility recovery respects a newly disabled guard and merges the latest service list, preserving other accessibility services.
- Includes the Coocaa / Skyworth Android 11 key-filter exception from #15.

## Cleanup and upgrades

- Automatic cleanup is cache-only and is off by default for new installations. Existing saved scheduling choices are retained. If the foreground app cannot be identified, automatic cleanup is skipped.
- Android 9 foreground detection supports mResumedActivity. Manual deep cleanup protects configured apps, foreground services, accessibility/notification services and visible media sessions. If media-session access is unavailable, third-party apps are conservatively protected.
- Stop commands are checked individually; the UI reports successful and failed commands rather than counting all targets as stopped.
- The installer preserves the existing keep-ADB preference unless KEEP_ADB=0 or KEEP_ADB=1 is explicitly supplied.

## Installation

Android 9 or later remains required. Download Tigris.apk for Standard or Tigris-guard.apk for Guard. Both use the existing stable release signing key for compatible in-place upgrades. Never uninstall an existing version merely to bypass a signature mismatch.

## Validation and limits

Regression tests cover missing foreground evidence, app/input transitions during a pending takeover, repeated stock-home takeovers, delayed service-repair races, Android 9 foreground parsing, cleanup filtering and command results. Both flavors have unit-test/build coverage; installer contracts and Android lint are release gates.

Issue #14 reports a Thunderbird 75S545C on Android 9 with v2.0.2 Guard. These changes address unsafe paths found in source; no logs or matching TV were available to reproduce its complete boot sequence or vendor freeze. That device still requires cold-boot, standby/wake, physical Home/volume keys and app/HDMI playback testing. Issue #14 remains open for that verification.

If firmware shows its home before the accessibility service binds and sends no subsequent window event, Tigris deliberately leaves that screen alone. Open Tigris or press Home instead of relying on an unverified boot takeover.
