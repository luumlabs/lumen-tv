Completes the Control Center fix from 3.0.1.

## Fixes

- **The Input control is now hidden entirely** on TVs that report no HDMI inputs. In 3.0.1 only its
  subtitle was hidden, which left an empty button in Control Center.

---

**Download:** `Lumen-v3.0.2.apk` (standard build). Newer releases also ship a guard build for TCL and FFalcon China firmware.
See the [installation guide](https://github.com/luumlabs/lumen-tv#installation).
