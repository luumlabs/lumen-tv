# Tigris 2.0.6

## Home screen ordering

- Added **主屏幕设置 → App → 最近打开的 App 自动置顶** (Settings → Apps → Recently opened apps first).
- **Disabled by default on first install and upgrade** so the current app order stays fixed unless the user explicitly opts in.
- Turn it on to move successfully opened apps or folders to the front. When disabled, launching an app never changes the grid order; long-press a tile and choose **编辑主屏幕** to rearrange manually. Turning it on or off never resets the saved layout.

## Versioned downloads

- Release downloads now include the tag in their filenames: `Tigris-v2.0.6.apk` and `Tigris-guard-v2.0.6.apk`.
- SHA-256 checksums: `SHA256SUMS-v2.0.6.txt`, containing the hashes and exact filenames.
- The in-app update checker and Bash installer accept versioned assets and still recognize the legacy unversioned asset names from earlier published releases.
- The Standard and Guard APKs use the stable signing key used since 2.0.4; do not uninstall an existing copy to work around a signature mismatch.

## Hardware verification

- JVM tests verify versioned asset selection and manual vs. automatic ordering; installer contract tests check old and new asset names and hash verification.
- Guard stability changes from 2.0.5 remain; the Thunderbird 75S545C boot-loop report (#14) still needs owner verification.
